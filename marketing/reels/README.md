# OpenNodes — 10 мультроликов (HTML-анимация → MP4)

Сценарии и раскадровка: [`../REELS-2026-11-09.md`](../REELS-2026-11-09.md).

## Как собрать

Нужны Google Chrome и `ffmpeg` (`brew install ffmpeg`).

```bash
cd marketing/reels
npm install                 # puppeteer-core, управляет установленным Chrome
node render.mjs             # все 10 → out/reel01.mp4 … out/reel10.mp4
node render.mjs 3 7         # только ролики 3 и 7
node render.mjs 3 --still 0.3 --still 12 --still-last   # стоп-кадры для проверки
./sheet.sh out/sheet.png out/reel03-*.png               # стоп-кадры одним листом
```

Посмотреть ролик в браузере в реальном времени: открыть `index.html?reel=3&play` через
любой локальный сервер (`python3 -m http.server`), иначе шрифт не подгрузится.

## Как устроено

- `kit.js`, `kit.css` — общий мультяшный стиль: персонажи (SVG, эмоции, моргание, рот при
  речи), робот, маскоты-ноды из иконки, **интерфейс OpenNodes в мультяшной отрисовке**
  (карточки шагов с цветной полосой категории, круглые входы данных и ромбы контекста,
  связи с бегущим пунктиром, пульсация шага при запуске, ✓/✕/■ на карточках, лампочка
  «Успех/Ошибка», кнопка «Проверить»), телефон с чатом, стикеры-плашки, реквизит.
- `reels/reelNN.js` — ролик: биты (фраза голоса = субтитры, плашка) и что рисовать на каждом.
- Кадр строится из времени `t`, без таймеров, поэтому рендер точный и повторяемый.
- Длительность бита = 0,4 с на слово (150 слов/мин), минимум 1,6 с — как в сценарии.
- Субтитры появляются по словам, текущее слово подсвечено. Хук-плашка видна с первого кадра,
  на каждой смене бита — наезд камеры. Последний кадр повторяет композицию первого (петля).
- Безопасная зона 9:16: всё важное в x 60–850, y 230–1440; правые 230 px и низ свободны
  под кнопки и подпись Instagram.

## Шрифт

Используется системный SF Pro Rounded: `render.mjs` копирует его в `.cache/` только на время
рендера. В репозиторий шрифт не попадает — лицензия Apple не разрешает его распространять.
На машине без него сработает запасной шрифт (Avenir Next / Helvetica).

## Голос

Озвучка — Higgsfield → ElevenLabs v4 (голоса Elena, Alexey, Vlad). Файлы лежат в `audio/`
(в git не попадают) и подхватываются рендером сами:

- `audio/reelNN/full.mp3` + `script.txt` — один дубль на весь ролик и текст, который
  читался (по строке на бит). Рендер распознаёт речь локальным Whisper
  (`brew install whisper-cpp`, модель `~/.cache/whisper/ggml-small.bin`), сопоставляет
  слова со сценарием и режет дубль там, где начинается каждая реплика.
- `audio/reelNN/beatXX.mp3` — либо по файлу на бит (так озвучен ролик 1).

Дальше для каждого бита: тишина по краям обрезается, речь ускоряется на 10%
(`VOICE_TEMPO=1.1`), длительность бита = длина реплики + 0,22 с, слова в субтитрах
подсвечиваются в момент, когда их произносят. Звук сводится к −16 LUFS.

Без папки `audio/reelNN` ролик собирается без звука, с таймингом 0,4 с на слово.
Музыку удобно добавить в CapCut.
