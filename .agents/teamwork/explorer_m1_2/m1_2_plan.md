# Milestone 1 Explorer 2 Plan: Database Layer & Drizzle Schema (Feature F02)

**Target Package:** `packages/db` (`@localflow/db`)  
**Scope:** 18 PostgreSQL tables, Drizzle ORM schemas, relations, indexes, foreign keys, envelope-encrypted credential fields, draft vs published workflow snapshots, execution journaling, in-memory mock DB adapter (`PGlite`), migration runner, and comprehensive Vitest test suite.  
**Integrity Mode:** Development (Zero Docker required for unit/contract tests).  

---

## 1. Executive Summary & Architectural Decisions

`packages/db` is the foundational data tier for LocalFlow. PostgreSQL is the authoritative single source of truth for metadata, credentials, workflows, execution states, and audit trails.

### Core Architectural Decisions:
1. **Drizzle ORM (`drizzle-orm/pg-core`)**:
   - Zero native C++ engine binaries (unlike Prisma).
   - Strict TypeScript compile-time type safety with automatic inference of `Select` and `Insert` models.
   - First-class support for relational queries (`db.query.*`).
2. **In-Memory Mock Adapter via `@electric-sql/pglite`**:
   - Compiles PostgreSQL 16 to WebAssembly running directly in Node.js.
   - Provides 100% PostgreSQL SQL dialect compatibility (UUIDs, JSONB, native ENUMs, foreign keys, transactions, indexes).
   - Enables fast, self-contained unit and integration testing without requiring a live Docker daemon or Postgres instance.
3. **Dual Client Interface**:
   - Production / Docker: `createPgDb(connectionString | pool)` using `drizzle-orm/node-postgres` and `pg.Pool`.
   - In-Memory / Testing: `createInMemoryDb()` using `drizzle-orm/pglite` and `@electric-sql/pglite`.
   - Both return an identical typed Drizzle database instance executing against the same 18-table schema.
4. **Envelope Encryption Compatibility**:
   - `credentials` table includes discrete fields: `keyVersion`, `iv`, `authTag`, `ciphertext`, and `maskedHint` to store AES-256-GCM ciphertexts generated by `packages/auth`.
5. **Workflow Versioning & Draft Isolation**:
   - `workflows` table maintains mutable draft canvas state (`draftNodes`, `draftEdges`, `draftTriggerConfig`, `draftExecutionPolicy`) and `activeVersionId`.
   - `workflow_versions` maintains immutable published snapshots with SHA-256 `checksum` and sequential `versionNumber`.
6. **Execution State Journaling**:
   - `executions` records run-level states (`QUEUED`, `RUNNING`, `WAITING`, `SUCCEEDED`, `FAILED`, `CANCELLED`).
   - `node_executions` records step-level transitions (`PENDING`, `RUNNING`, `SUCCEEDED`, `FAILED`, `SKIPPED`, `CANCELLED`) with sanitized JSONB inputs/outputs for crash recovery and auditability.
   - `execution_logs` and `execution_events` provide micro-level diagnostic logging and SSE event streaming.

## 2. Table Inventory (All 18 Tables)

| # | Table Name | TypeScript Export | Primary Responsibility | Key Constraints & Relations |
|---|------------|-------------------|------------------------|-----------------------------|
| 1 | `users` | `users` | User identity & authentication | `email` UNIQUE, `isOwner` flag, cascade deletes memberships |
| 2 | `sessions` | `sessions` | Web and API session tokens | FK `userId` -> `users.id` (CASCADE), `expiresAt` |
| 3 | `workspaces` | `workspaces` | Logical tenant workspace isolation | `slug` UNIQUE, cascades workflows/credentials/executions |
| 4 | `memberships` | `memberships` | 4-tier RBAC (`OWNER`, `ADMIN`, `EDITOR`, `VIEWER`) | UNIQUE `(userId, workspaceId)`, FKs to `users` and `workspaces` |
| 5 | `invitations` | `invitations` | Workspace member invitation tokens | `token` UNIQUE, `(workspaceId, email)`, expiration timestamp |
| 6 | `audit_logs` | `auditLogs` | Immutable audit trail for security operations | FK `workspaceId`, FK `userId` (SET NULL), action, resource, details |
| 7 | `workflows` | `workflows` | Workflow definition & draft state | FK `workspaceId`, `activeVersionId`, JSONB draft graph fields |
| 8 | `workflow_versions` | `workflowVersions` | Immutable published snapshots | UNIQUE `(workflowId, versionNumber)`, SHA-256 `checksum` |
| 9 | `credentials` | `credentials` | Envelope-encrypted credentials | `keyVersion`, `iv`, `authTag`, `ciphertext`, `maskedHint` |
| 10 | `executions` | `executions` | Workflow run records & states | FK `workflowId`, FK `workflowVersionId`, status ENUM, idempotencyKey |
| 11 | `node_executions` | `nodeExecutions` | Step-level execution journal | FK `executionId`, `nodeId`, sanitized `inputPayload`/`outputPayload` |
| 12 | `execution_logs` | `executionLogs` | Diagnostic execution logs | FK `executionId`, FK `nodeExecutionId`, log level, timestamp |
| 13 | `execution_events` | `executionEvents` | Real-time SSE execution events | FK `executionId`, `eventType`, JSONB event payload |
| 14 | `triggers` | `triggers` | Workflow trigger configs (Cron/Telegram) | FK `workflowId`, trigger type, JSONB config, enabled flag |
| 15 | `trigger_logs` | `triggerLogs` | Trigger firing execution logs | FK `triggerId`, FK `executionId`, status, payload |
| 16 | `webhook_subscriptions` | `webhookSubscriptions` | Webhook ingress endpoints | `endpointToken` UNIQUE, HMAC secret hash, HTTP method |
| 17 | `api_keys` | `apiKeys` | Service API keys for external access | `keyHash` UNIQUE, `keyPrefix`, role, expiration |
| 18 | `workspace_settings` | `workspaceSettings` | Workspace-level governance & SSRF allowlist | UNIQUE `workspaceId`, executionTimeout, maxConcurrency, ssrfAllowlist |

import { drizzle as drizzlePg, NodePgDatabase } from 'drizzle-orm/node-postgres';
import { drizzle as drizzlePglite, PgliteDatabase } from 'drizzle-orm/pglite';
import { Pool, PoolConfig } from 'pg';
import { PGlite } from '@electric-sql/pglite';
import * as schema from './schema/index.js';
import { syncSchema } from './migrator.js';

export type AppSchema = typeof schema;
export type PgDatabaseInstance = NodePgDatabase<AppSchema>;
export type PgliteDatabaseInstance = PgliteDatabase<AppSchema>;
export type DatabaseInstance = PgDatabaseInstance | PgliteDatabaseInstance;

export interface CreatePgDbOptions {
  connectionString?: string;
  poolConfig?: PoolConfig;
  pool?: Pool;
}

/**
 * Creates a Drizzle database client connected to a real PostgreSQL instance.
 */
export function createPgDb(options: CreatePgDbOptions = {}): PgDatabaseInstance {
  let pool: Pool;
  if (options.pool) {
    pool = options.pool;
  } else if (options.connectionString) {
    pool = new Pool({ connectionString: options.connectionString });
  } else if (options.poolConfig) {
    pool = new Pool(options.poolConfig);
  } else {
    const connStr = process.env.DATABASE_URL ?? 'postgres://localflow:localflow@localhost:5432/localflow';
    pool = new Pool({ connectionString: connStr });
  }
  return drizzlePg(pool, { schema });
}

/**
 * Creates an in-memory PGlite database instance for tests,
 * automatically applying the schema DDL so it is immediately ready.
 */
export async function createInMemoryDb(): Promise<PgliteDatabaseInstance> {
  const client = new PGlite();
  const db = drizzlePglite(client, { schema });
  await syncSchema(db);
  return db;
}

  name VARCHAR(255) NOT NULL,
  is_enabled BOOLEAN NOT NULL DEFAULT TRUE,
  config JSONB NOT NULL DEFAULT '{}'::jsonb,
  last_triggered_at TIMESTAMPTZ,
  next_trigger_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS idx_triggers_workspace ON triggers(workspace_id);
CREATE INDEX IF NOT EXISTS idx_triggers_workflow ON triggers(workflow_id);
CREATE INDEX IF NOT EXISTS idx_triggers_type_enabled ON triggers(type, is_enabled);

-- 16. Trigger Logs
CREATE TABLE IF NOT EXISTS trigger_logs (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  trigger_id UUID NOT NULL REFERENCES triggers(id) ON DELETE CASCADE,
  execution_id UUID REFERENCES executions(id) ON DELETE SET NULL,
  status VARCHAR(32) NOT NULL DEFAULT 'success',
  payload JSONB,
  error_message TEXT,
  triggered_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS idx_trigger_logs_trigger ON trigger_logs(trigger_id, triggered_at);
CREATE INDEX IF NOT EXISTS idx_trigger_logs_execution ON trigger_logs(execution_id);

-- 17. Webhook Subscriptions
CREATE TABLE IF NOT EXISTS webhook_subscriptions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  workspace_id UUID NOT NULL REFERENCES workspaces(id) ON DELETE CASCADE,
  workflow_id UUID NOT NULL REFERENCES workflows(id) ON DELETE CASCADE,
  endpoint_token VARCHAR(64) NOT NULL UNIQUE,
  http_method VARCHAR(16) NOT NULL DEFAULT 'POST',
  secret_hash VARCHAR(255),
  auth_type webhook_auth_type NOT NULL DEFAULT 'NONE',
  is_active BOOLEAN NOT NULL DEFAULT TRUE,
  idempotency_header VARCHAR(64),
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS idx_webhook_subs_token ON webhook_subscriptions(endpoint_token);
CREATE INDEX IF NOT EXISTS idx_webhook_subs_workspace ON webhook_subscriptions(workspace_id);
CREATE INDEX IF NOT EXISTS idx_webhook_subs_workflow ON webhook_subscriptions(workflow_id);

-- 18. Audit Logs
CREATE TABLE IF NOT EXISTS audit_logs (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  workspace_id UUID NOT NULL REFERENCES workspaces(id) ON DELETE CASCADE,
  user_id UUID REFERENCES users(id) ON DELETE SET NULL,
  action VARCHAR(100) NOT NULL,
  resource_type VARCHAR(100) NOT NULL,
  resource_id VARCHAR(255) NOT NULL,
  details JSONB,
  ip_address VARCHAR(64),
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS idx_audit_logs_workspace_created ON audit_logs(workspace_id, created_at);
CREATE INDEX IF NOT EXISTS idx_audit_logs_user ON audit_logs(user_id);
CREATE INDEX IF NOT EXISTS idx_audit_logs_resource ON audit_logs(resource_type, resource_id);
`;
}

/**
 * Synchronizes the schema by executing the canonical DDL statements.
 */
export async function syncSchema(db: DatabaseInstance): Promise<void> {
  const statements = getInitialMigrationSql();
  await db.execute(sql.raw(statements));
}

/**
 * Migration runner suitable for production or CLI execution.
 */
export async function runMigrations(db: DatabaseInstance): Promise<void> {
  await syncSchema(db);
}

import { describe, it, expect, beforeEach } from 'vitest';
import { eq } from 'drizzle-orm';
import { createInMemoryDb, PgliteDatabaseInstance } from '../src/client.js';
import * as schema from '../src/schema/index.js';

describe('packages/db: In-Memory PostgreSQL Schema & Relational CRUD', () => {

  it('initializes in-memory database with all 18 tables', async () => {

  it('performs CRUD on users and workspaces with unique constraint enforcement', async () => {

      passwordHash: 'argon2id$mockhash',

    }).returning();
    expect(user.id).toBeDefined();
    expect(user.email).toBe('owner@localflow.dev');
    expect(user.isOwner).toBe(true);

    // 2. Reject duplicate user email
    await expect(
      db.insert(schema.users).values({
        email: 'owner@localflow.dev',
        passwordHash: 'another$hash',
      })
    ).rejects.toThrow();

    // 3. Create Workspace
    const [workspace] = await db.insert(schema.workspaces).values({
      name: 'Primary Workspace',
      slug: 'primary-workspace',

    expect(workspace.id).toBeDefined();
    expect(workspace.slug).toBe('primary-workspace');

    // 4. Reject duplicate workspace slug
    await expect(
      db.insert(schema.workspaces).values({
        name: 'Another Workspace',
        slug: 'primary-workspace',
      })
    ).rejects.toThrow();

    // 5. Create Membership
    const [membership] = await db.insert(schema.memberships).values({
      userId: user.id,

    await expect(
      db.insert(schema.memberships).values({
        userId: user.id,
        workspaceId: workspace.id,
        role: 'VIEWER',

      name: 'Workflow Workspace',

    // Create Draft Workflow

      draftTriggerConfig: { type: 'manual' },

    const [step1] = await db.insert(schema.nodeExecutions).values({
      executionId: execution.id,
      nodeId: 'http_request_1',
      nodeType: 'core.httpRequest',

    // 4. Add Step Logs and Events

      message: 'Dispatching HTTP GET request',
    });

    await db.insert(schema.executionEvents).values({
      executionId: execution.id,
      eventType: 'node:started',
      nodeId: 'http_request_1',
      payload: { stepId: step1.id },
    });

    // 5. Complete Step with Redacted Output
    const finishedAt = new Date();
    await db.update(schema.nodeExecutions)

        status: 'SUCCEEDED',
